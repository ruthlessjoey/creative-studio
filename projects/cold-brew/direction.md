# Direction: Cold Brew v2
Idea: type is the glass. Giant stacked words in coffee browns that fade light (COLD, BREW, SLOW), with real-looking cold brew streams pouring through the letters.
Parts borrowed from references: stacked gradient type + liquid (DRIP), huge heavy type with a red script accent (DROPPED), spec-sheet rules, mono microcopy and (c) mark (BREWING), dry one-line wit (text bubbles).
Palette (measured from refs with Pillow median-cut, approximate): paper #EDE8DE, espresso #2A160A, roast #5B3220, latte #9A7A58, liquid amber #C9731F to #E39A3C, accent red #B0121C.
Type: Archivo (wide, weight 900) display, Archivo 500 labels, DM Mono specs, Kaushan Script accent. All OFL, subset and embedded (assets/fonts).
Texture: SVG feTurbulence film grain, multiplied.
Motion (video/site): streams descend with ease-in then stretch/snap into drops; type rows slide in staggered; script "12 hrs" writes on; hold on spec sheet. Target 60 fps, GSAP.
